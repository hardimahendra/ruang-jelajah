# Ruang Jelajah — Next.js

**Live demo:** https://ruang-jelajah.vercel.app

Modernisasi proyek statis Travel Coding (proyek lama) menjadi katalog perjalanan frontend-only.

- Jalankan `npm install` lalu `npm run dev`.
- Endpoint demo: `GET /api/destinasi`.
- Tidak ada pembayaran, pemesanan, atau penyimpanan data.
