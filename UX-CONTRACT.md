# Ruang Jelajah — UX Contract

| Operasi         | Trigger         | Hasil                                               | Pemulihan                                                   |
| --------------- | --------------- | --------------------------------------------------- | ----------------------------------------------------------- |
| Mencari tujuan  | Kolom pencarian | Kartu disaring secara lokal                         | Tombol hapus mengosongkan pencarian segera                  |
| Memilih suasana | Filter          | Hanya kategori relevan tampil                       | “Semua” mengembalikan katalog                               |
| Membuka rencana | `Lihat rencana` | Dialog berisi durasi, anggaran, layanan, dan sumber | Escape, tombol tutup, atau klik lapisan luar menutup dialog |
| Membuka sumber  | Tautan sumber   | Rujukan resmi terbuka di tab baru                   | Pengguna tetap berada pada katalog asal                     |

Katalog tidak menerima pemesanan. Seluruh tindakan yang tampak seperti perencanaan menjelaskan bahwa pengguna perlu memverifikasi detail dengan penyedia atau pengelola lokasi.
